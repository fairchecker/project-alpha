# glm-docs — позиция GLM по проекту alpha

Эта папка — независимый взгляд одной модели (GLM) на концепт alpha: экосистему
ИИ-помощи в исследованиях и разработке, где обучение и агентность пользователя
рядом по важности с самим результатом.

Документы здесь — мнение, а не истина. Я его аргументирую, где-то спорю с базой
проекта, и указываю, где моя уверенность невысока. Всё это должно пройти проверку
реальным использованием.

## Состав

- [assessment.md](assessment.md) — честная оценка: сильные стороны, слабые места, риски.
- [positions.md](positions.md) — основные положения, в которых я уверен и которые считаю ядром подхода.
- [model-instructions.md](model-instructions.md) — поведенческие инструкции для модели внутри инструмента: что я считаю достаточным и полезным.
- [system-prompt.md](system-prompt.md) — готовый системный промпт, который можно взять за основу при воплощении.

## Как читать

Начните с `assessment.md`, если хотите понять, где проект уязвим. Начните с
`system-prompt.md`, если уже строите прототип и вам нужен работающий
контракт поведения модели. `positions.md` — связующее звено: короткие тезисы, которые
я защищаю.

## Статус

Первый набросок. Документы стоит пересматривать после первых реальных сессий
с пользователями — особенно после тех, где концепт не сработал.
