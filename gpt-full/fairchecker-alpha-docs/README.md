# Alpha — пакет проектной документации

**Статус:** рабочее предложение (Draft)  
**Версия пакета:** 0.1.0  
**Дата сборки:** 2026-11-10

Этот архив содержит консолидированную проектную документацию и начальный набор промптов для Alpha. Материалы подготовлены как самостоятельное предложение по развитию концепции: они не являются утверждённой спецификацией и не заменяют исходные документы репозитория.

## Идея в одном абзаце

Alpha — проектная среда с управляемым ИИ-агентом. Она помогает вести длительные задачи, исследовать, проектировать и создавать артефакты, сохраняя контекст, решения и проверяемые результаты. Пользователь определяет цели, допустимую автономность, учебный бюджет и полномочия инструментов. Обучение — дополнительная возможность, а не обязательный режим каждого взаимодействия.

## Ключевые архитектурные решения предложения

1. **Результат и обучение — независимые цели.** `artifact_goal` не следует смешивать с `learning_goal`.
2. **Режимы помощи — пресеты, а не жёсткая взаимоисключающая модель.** Распределение исполнения, глубина объяснений, учебный бюджет и разрешения задаются отдельно.
3. **Полномочия проверяет приложение.** Системный промпт не является механизмом контроля доступа.
4. **Память хранит состояние и решения, а не только переписку.**
5. **Выполнение отделено от проверки.** Сообщение модели о завершении не заменяет тесты и проверку артефактов.
6. **Несколько моделей не голосуют за истину.** Их результаты — независимые аргументы, требующие сопоставления и проверки.
7. **Пользователь остаётся владельцем целей, данных и решений проекта.**

## Важная оговорка

Промпты в этом архиве — поведенческие контракты для модели. Они не заменяют программные ограничения, схемы валидации, журналирование, sandboxing, контроль сетевого доступа и проверку операций на стороне приложения.
