# 04. Режимы помощи

**Статус:** Draft proposal

## 1. Проблема исходной модели

Режимы `Question`, `Hint`, `Collaborate`, `Demonstrate` и `Delegate` полезны как понятные пресеты, но не являются взаимоисключающими категориями одного уровня. Например, делегированная реализация может сопровождаться демонстрацией ключевого решения.

Поэтому пресеты следует построить поверх нескольких независимых параметров.

## 2. Независимые параметры

### Execution policy

| Значение | Поведение |
|---|---|
| `user_led` | Пользователь выполняет основную работу; агент помогает ориентироваться и проверять |
| `collaborative` | Человек и агент совместно принимают решения и выполняют шаги |
| `agent_led` | Агент выполняет согласованную задачу в пределах полномочий |

### Explanation policy

`minimal`, `normal`, `detailed` — определяет глубину объяснения результата.

### Learning budget

`none`, `low`, `medium` — ограничивает незапрошенные учебные инициативы. Прямой запрос пользователя на объяснение не блокируется.

### Tool permissions

Определяются отдельной политикой и не выводятся из выбранного режима помощи.

## 3. Рекомендуемые пресеты

| Пресет | Execution | Explanation | Типичное применение |
|---|---|---|---|
| `Question` | `user_led` | `normal` | Разобраться в проблеме и уточнить постановку |
| `Hint` | `user_led` | `minimal` | Получить следующий ориентир, не раскрывая решение целиком |
| `Collaborate` | `collaborative` | `normal` | Совместное проектирование и обсуждение вариантов |
| `Demonstrate` | зависит от задачи | `detailed` | Получить полный пример с объяснением |
| `Delegate` | `agent_led` | `normal` | Передать согласованный объём работы агенту |

Пресет устанавливает начальные значения, но пользователь может менять их независимо.

## 4. Правила переключения

- Явная текущая инструкция пользователя имеет приоритет над пресетом.
- Переключение режима не расширяет полномочия инструментов.
- Агент не должен искусственно удерживать пользователя в учебном режиме.
- При смене режима уже принятые решения и состояние задачи сохраняются.
