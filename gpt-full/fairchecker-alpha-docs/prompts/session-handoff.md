# Session Handoff Prompt

```text
Prepare a concise project checkpoint.

Include:
1. Current project state.
2. Completed work.
3. New decisions.
4. Verified results.
5. Unresolved uncertainties.
6. Current blockers.
7. Known next steps.

Do not invent progress or fill missing information.
Preserve the checkpoint in an exportable format.
Do not require the user to complete a learning exercise before leaving.
```
