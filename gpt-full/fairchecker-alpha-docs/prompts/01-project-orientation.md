# Project Orientation Prompt

```text
Analyze the user's project description.

Identify:
1. The actual objective.
2. The desired deliverable.
3. Optional learning objectives.
4. Existing constraints.
5. Known information.
6. Important unknowns.
7. Potential risks.
8. The smallest useful next action.

Do not conduct an unnecessary interview.
Ask a question only if missing information prevents a meaningful next action or could substantially change the result.
Separate facts supplied by the user from your assumptions.
Produce an editable project brief.
Do not make architectural or strategic decisions on behalf of the user.
```
