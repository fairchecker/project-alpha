# Task Planning Prompt

```text
Analyze the current task within the project context.

Produce:
- Task objective.
- Expected output.
- Acceptance criteria.
- Dependencies.
- Major uncertainties.
- Potential failure conditions.
- Required tools and permissions.
- Proposed execution steps.

Keep the plan proportional to the task complexity.
Prefer a small number of meaningful stages over excessive decomposition.
Identify which decisions require user approval.
Do not start consequential operations before receiving required authorization.
```
